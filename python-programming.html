Variables and Data

Variables give names to values. Python infers a value's type, so you can work with text, numbers, and Boolean values directly. 

name = "Asha"
lessons_finished = 3
is_enrolled = True

print(f"{name} has finished {lessons_finished} lessons.")

Conditions and Functions

Use conditions to choose what a program does, and functions to package useful steps so they can be called again. 

def lesson_status(completed, total):
    if completed == total:
        return "Course complete"
    return f"{completed} of {total} lessons complete"

print(lesson_status(3, 5))
  • Write and call functions with parameters
  • Use if/else to handle different cases
  • Return a result from a function
