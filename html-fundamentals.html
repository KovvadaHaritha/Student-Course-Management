📘 HTML Fundamentals

Learn the basics of HTML and how webpages are structured.

What is HTML?

HTML stands for HyperText Markup Language. It is used to create the structure of webpages.

HTML uses elements and tags to define headings, paragraphs, links, images and other content.

What You Will Learn

  • HTML document structure
  • Headings and paragraphs
  • Links and images
  • Lists and forms
  • Basic webpage structure

💻 Your First HTML Page

A basic HTML page looks like this: 

<!DOCTYPE html>
<html>

<head>
    <title>My Page</title>
</head>

<body>
    <h1>Hello World</h1>
    <p>Welcome to HTML!</p>
</body>

</html>
