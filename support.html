Report an issue and track its status in this browser session.

Common recovery steps

  • Course access: reload the course page; if the issue continues, include the course name and page URL in your report.
  • Broken lesson or video: try the official documentation link and report the broken URL.
  • Project submission: check file type and the 5 MB limit, then retry once.
  • Payment: check payment history before retrying. Never send card, PIN, CVV or banking passwords.
  • Assessment: drafts are saved as answers are selected; reload the same assessment to resume.
