CSS & Responsive Design

Style webpages and adapt layouts to different screen sizes.

What is CSS?

CSS stands for Cascading Style Sheets. It controls how HTML content looks, including colors, spacing, typography and layout.

Flexbox and Grid help arrange content, while media queries let a layout respond to the available screen width.

What you will learn

  • CSS selectors and declarations
  • Colors, spacing and typography
  • Flexible layouts with Flexbox and Grid
  • Responsive breakpoints with media queries
  • Mobile-first design principles

A Responsive CSS Rule

Use a media query to switch to a single-column layout on narrow screens: 

.lesson-grid {
    display: grid;
    grid-template-columns: repeat(2, 1fr);
    gap: 24px;
}

@media (max-width: 700px) {
    .lesson-grid {
        grid-template-columns: 1fr;
    }
}

JavaScript Basics

JavaScript adds behavior to a webpage. Start with values, variables, functions, and event listeners.

const button = document.querySelector("button");

button.addEventListener("click", function () {
    alert("Button clicked!");
});
